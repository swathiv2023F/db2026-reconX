# ReconX — Team 3 — Retrospective

## What worked?
- The reference materials and documentation were very helpful when implementing new features.
- Dividing the work based on what we learned each day helped us stay organised and make steady progress.

## What didn't?
- Setting up and troubleshooting Maven and Spring Boot, especially on the virtual machine, caused delays.
- Some environment and configuration issues took longer to resolve than expected.

## What would you change?
- Spend more time covering the core concepts before moving into implementation.
- Better balance the amount of work with the time available for each day.

## What surprised you?
- How much configuration was required compared to writing the actual application code.

## Technical notes for the next cohort
- Make sure the tickets stay aligned with the provided starter code to avoid unnecessary confusion and rework.
- Read the ticket acceptance criteria carefully before starting, as small details can affect the implementation.
